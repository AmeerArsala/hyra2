# LLM Wiki — agent instructions

This directory is an LLM-maintained knowledge vault (Karpathy's LLM Wiki pattern). It works with any coding
agent that reads `AGENTS.md`. The workflows live in the **hyra-wiki** skill (installed at `{{SKILL_DIR}}` when
this vault was created); load that skill (or read its `SKILL.md`) before doing wiki work.

## Layers
```
raw/   immutable, hashed source documents          (only scribe / researcher append)
wiki/  derived pages with citations + confidence    (typed: concepts, decisions, comparisons, synthesis, ...)
query  answers cite wiki pages with [[wikilinks]]   (advisor reads wiki/ only, never raw/)
```

## Hard contracts
1. Only the **scribe** and **researcher** roles write to `raw/`, append-only. Never edit or delete raw files.
2. Every typed wiki page has `sources` / citations back to `raw/` or a URL. No claim without a source.
3. The **advisor** reads `wiki/` only and says "not in the wiki" rather than guessing.
4. New or machine-written pages start as `status: draft` (or in `wiki/_drafts/`) and are promoted by the curator.
5. Keep `index.md` ≤100 links and hubs ≤15 members; use the scripts, don't hand-edit indexes.
6. Never put secrets or private data in `raw/` or `wiki/`. Web capture is local-only unless the user opts in to cloud.

## Roles (adopt one per task; see `roles/` in the skill)
researcher: "research X" · scribe: "save this URL/PDF/text" · advisor: "what does the wiki say about X" ·
curator: "audit / clean up / migrate the wiki".

Vault config: `wiki.config.md`. Rolling session cache: `wiki/hot.md`. Index: `index.md` at the vault root (generated by `update-index.sh`).
